BREACHLINE is a round-based tactical FPS in the browser: defend the Foundry with four Vanguard bots against five Specter bots who push two spike sites, with a buy phase, economy, plant/defuse objective, and first-to-8 rounds — all running offline from static files on three.js.

## Run it

```sh
node serve.mjs
```

Then open http://localhost:8080 in a desktop browser with WebGL 2. Click to deploy, buy with keys 1–5 during the buy phase, ENTER to deploy early.
